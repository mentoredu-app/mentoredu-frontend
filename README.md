# MentorEdu Frontend

Aplicación web principal de la plataforma MentorEdu. Desarrollada en Angular 21 y desplegada en Netlify.

## Stack

- Angular 21 (standalone components, zoneless)
- TypeScript
- Netlify (hosting)

## Live

https://mentor-edu-frontend.netlify.app
