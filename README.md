# MentorEdu Frontend

Aplicación web principal de la plataforma MentorEdu. Desarrollada en Angular 21 y desplegada en Netlify.

## Stack

- Angular 21 (standalone components, zoneless)
- TypeScript
- Netlify (hosting)

## Proyectos relacionados

- [MentorEdu API](https://github.com/mentoredu-app/mentoredu-api) — API REST principal
- [File Service](https://github.com/mentoredu-app/File-service) — gestión de archivos
- [Landing Page](https://github.com/mentoredu-app/mentoredu-landing) — página de presentación
